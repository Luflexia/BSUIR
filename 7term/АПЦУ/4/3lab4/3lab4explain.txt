
╔══════════════════════════════════════════════════════════════════════════════╗
║         СДВИГОВЫЙ РЕГИСТР С АВТОМАТИЧЕСКОЙ ЧАСТОТОЙ 1 Гц                    ║
║                      ПОЛНАЯ ИНСТРУКЦИЯ                                       ║
╚══════════════════════════════════════════════════════════════════════════════╝

ВАЖНО: В этой версии регистр работает АВТОМАТИЧЕСКИ на частоте 1 Гц
       Каждую секунду происходит один такт регистра (загрузка или сдвиг)
       Кнопка R5 (CP) больше НЕ ИСПОЛЬЗУЕТСЯ

================================================================================
                         КАК РАБОТАЕТ СИСТЕМА
================================================================================

1. ДЕЛИТЕЛЬ ЧАСТОТЫ: Системная частота 200 МГц делится на 200 000 000
   Результат: тактовый сигнал 1 Гц (один фронт каждую секунду)

2. АВТОМАТИЧЕСКАЯ ТАКТИРОВКА: Регистр обновляется каждую секунду автоматически
   - Если PE_n нажата (загрузка): каждую секунду загружаются данные из D[3:0]
   - Если PE_n отпущена (сдвиг): каждую секунду данные сдвигаются на 1 бит

3. НАБЛЮДЕНИЕ: Вы можете видеть изменения на светодиодах раз в секунду

╔══════════════════════════════════════════════════════════════════════════════╗
║                     НАЗНАЧЕНИЕ КНОПОК (4 штуки)                             ║
╚══════════════════════════════════════════════════════════════════════════════╝

┌──────────────────────────────────────────────────────────────────────────┐
│ КНОПКА 1: P6 (GPIO_SW_N) → MR_n (Master Reset)                          │
├──────────────────────────────────────────────────────────────────────────┤
│ • НАЖАТА: Сброс регистра (Q[3:0] = 0000)                                │
│ • ОТПУЩЕНА: Нормальная работа                                           │
│ • Работает мгновенно (асинхронный сброс)                                │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ КНОПКА 2: U6 (SW_W) → PE_n (Parallel Enable)                            │
├──────────────────────────────────────────────────────────────────────────┤
│ • НАЖАТА: Режим параллельной загрузки                                   │
│   → Каждую секунду загружаются данные из DIP-switches D[3:0]           │
│                                                                          │
│ • ОТПУЩЕНА: Режим последовательного сдвига                              │
│   → Каждую секунду данные сдвигаются вправо на 1 позицию               │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ КНОПКА 3: U5 (SW_E) → J (Serial Input)                                  │
├──────────────────────────────────────────────────────────────────────────┤
│ • Работает только в режиме сдвига (PE_n отпущена)                       │
│ • НАЖАТА = 1 будет входить в Q0 при сдвиге                              │
│ • ОТПУЩЕНА = 0 будет входить в Q0 при сдвиге                            │
└──────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│ КНОПКА 4: T5 (SW_S) → K_n (Serial Input, active low)                    │
├──────────────────────────────────────────────────────────────────────────┤
│ • Работает только в режиме сдвига (PE_n отпущена)                       │
│ • Используется вместе с J для управления входным битом                  │
│ • НАЖАТА = K=1 (K_n=0)                                                  │
│ • ОТПУЩЕНА = K=0 (K_n=1)                                                │
└──────────────────────────────────────────────────────────────────────────┘

⚠️  КНОПКА R5 (SW_N) не используется в этой версии (тактирование автоматическое)

╔══════════════════════════════════════════════════════════════════════════════╗
║                    DIP-ПЕРЕКЛЮЧАТЕЛИ (4 штуки)                              ║
╚══════════════════════════════════════════════════════════════════════════════╝

R8 → D[0] (младший бит, LSB)
P8 → D[1]
R7 → D[2]
R6 → D[3] (старший бит, MSB)

Устанавливают 4-битное значение для параллельной загрузки
ВВЕРХ = 1, ВНИЗ = 0

╔══════════════════════════════════════════════════════════════════════════════╗
║                    СВЕТОДИОДЫ И ИХ ЗНАЧЕНИЕ                                 ║
╚══════════════════════════════════════════════════════════════════════════════╝

ОСНОВНАЯ ПЛАТА AC701 (4 светодиода):
─────────────────────────────────────
M26 → Q[0] - младший бит (первый триггер)
T24 → Q[1] - второй бит
T25 → Q[2] - третий бит
R26 → Q[3] - старший бит (четвертый триггер)

Показывают текущее 4-битное состояние регистра
СВЕТИТСЯ = 1, НЕ СВЕТИТСЯ = 0

ВНЕШНЯЯ ПЛАТА (1 светодиод):
─────────────────────────────
F25 → Q3_n - инверсия Q[3]
Если Q[3] светится → Q3_n не светится (и наоборот)

╔══════════════════════════════════════════════════════════════════════════════╗
║                       ПРАКТИЧЕСКИЕ ПРИМЕРЫ                                  ║
╚══════════════════════════════════════════════════════════════════════════════╝

═══════════════════════════════════════════════════════════════════════════════
ПРИМЕР 1: Непрерывная параллельная загрузка
═══════════════════════════════════════════════════════════════════════════════
Цель: Наблюдать, как регистр загружает значение каждую секунду

1. Установите DIP-switches: D[3:0] = 1010 (R6↑ R7↓ P8↑ R8↓)
2. НАЖМИТЕ PE_n (U6) - включить режим загрузки
3. Отпустите MR_n (P6) - разрешить работу

НАБЛЮДЕНИЕ:
- Каждую секунду регистр загружает значение 1010
- Светодиоды Q[3:0] показывают: R26 ON, T25 OFF, T24 ON, M26 OFF
- Если изменить DIP-switches, через 1 секунду светодиоды изменятся

═══════════════════════════════════════════════════════════════════════════════
ПРИМЕР 2: Автоматический сдвиг вправо с обнулением
═══════════════════════════════════════════════════════════════════════════════
Цель: Увидеть, как данные постепенно "выходят" из регистра

1. Загрузите начальное значение 1111:
   - Установите D[3:0] = 1111 (все DIP вверх)
   - НАЖМИТЕ PE_n (U6) - загрузка
   - Подождите 1 секунду (Q[3:0] станет 1111)

2. Переключитесь на режим сдвига:
   - ОТПУСТИТЕ PE_n (U6) - режим сдвига
   - ОТПУСТИТЕ J (U5) и K_n (T5) - на вход идет 0

3. НАБЛЮДЕНИЕ (каждую секунду):
   t=0с:  Q[3:0] = 1111 (все светятся)
   t=1с:  Q[3:0] = 0111 (сдвиг, слева вошел 0)
   t=2с:  Q[3:0] = 0011
   t=3с:  Q[3:0] = 0001
   t=4с:  Q[3:0] = 0000 (все данные вышли)
   t=5с:  Q[3:0] = 0000 (продолжается сдвиг нулей)

═══════════════════════════════════════════════════════════════════════════════
ПРИМЕР 3: Сдвиг с вводом единиц
═══════════════════════════════════════════════════════════════════════════════
Цель: Заполнить регистр единицами слева направо

1. Сброс: НАЖМИТЕ MR_n (P6), затем отпустите → Q[3:0] = 0000

2. Настройте режим сдвига с вводом 1:
   - ОТПУСТИТЕ PE_n (U6) - режим сдвига
   - НАЖМИТЕ J (U5) - на вход идет 1
   - ОТПУСТИТЕ K_n (T5)

3. НАБЛЮДЕНИЕ (каждую секунду):
   t=0с:  Q[3:0] = 0000
   t=1с:  Q[3:0] = 1000 (в Q0 вошла 1)
   t=2с:  Q[3:0] = 1100 (еще одна 1 вошла)
   t=3с:  Q[3:0] = 1110
   t=4с:  Q[3:0] = 1111 (регистр заполнен)
   t=5с:  Q[3:0] = 1111 (продолжается сдвиг единиц)

═══════════════════════════════════════════════════════════════════════════════
ПРИМЕР 4: Динамическое переключение режимов
═══════════════════════════════════════════════════════════════════════════════
Цель: Комбинировать загрузку и сдвиг

1. Загрузите 1010:
   - D[3:0] = 1010, НАЖМИТЕ PE_n (U6)
   - Подождите 1 секунду → Q[3:0] = 1010

2. Сдвиньте 2 раза:
   - ОТПУСТИТЕ PE_n (U6), J(U5), K_n(T5)
   - Подождите 2 секунды → Q[3:0] = 0010

3. Загрузите новое значение 0101:
   - Измените D[3:0] = 0101
   - НАЖМИТЕ PE_n (U6)
   - Подождите 1 секунду → Q[3:0] = 0101

4. Продолжите сдвиг...

1. ShiftRegister_1Hz_Top.vhd      ← TOP-модуль (используйте его как top)
2. ParallelShiftRegister.vhd      ← Основной регистр (shift_reg.txt)

4. ShiftRegister_1Hz_Top.xdc      ← Файл ограничений (constraints)

╔══════════════════════════════════════════════════════════════════════════════╗
║                      ШАГИ СОЗДАНИЯ В VIVADO                                 ║
╚══════════════════════════════════════════════════════════════════════════════╝

1. Создайте новый проект в Vivado
2. Выберите плату: Xilinx AC701 Evaluation Board
3. Добавьте VHDL файлы:
   - ShiftRegister_1Hz_Top.vhd (установите как top module)
   - ParallelShiftRegister.vhd
   - JK_trigger.vhd

4. Добавьте XDC файл:
   - ShiftRegister_1Hz_Top.xdc

5. Run Synthesis → Run Implementation → Generate Bitstream

6. Program Device

╔══════════════════════════════════════════════════════════════════════════════╗
║                      ОТЛАДКА И ПРОВЕРКА                                     ║
╚══════════════════════════════════════════════════════════════════════════════╝

Если регистр не работает правильно:

1. ✓ Проверьте, что MR_n (P6) ОТПУЩЕНА (не нажата)
   → Если нажата, регистр всегда будет в сбросе (0000)

2. ✓ Убедитесь, что делитель частоты работает
   → Добавьте в constraints: set_property CLOCK_DEDICATED_ROUTE FALSE [get_nets clk_1Hz]

3. ✓ Проверьте режим работы PE_n:
   → НАЖАТА = загрузка, ОТПУЩЕНА = сдвиг

4. ✓ Для режима сдвига убедитесь, что J и K_n установлены правильно
   → Для ввода 0: J отпущена, K_n отпущена
   → Для ввода 1: J нажата, K_n отпущена

5. ✓ Проверьте, что DIP-switches установлены правильно
   → ВВЕРХ = 1, ВНИЗ = 0
