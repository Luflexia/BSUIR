Visual Studio
1. Качаем nvidia toolkit (https://developer.nvidia.com/cuda-downloads)
2. Создаем проект в VS по шаблону CUDA 13.0 Runtime (он появится после установки тулкита)
3. ПКМ по проекту (под Решение находится, в обозревателе решений), Компоновщик, Ввод, Дополнительные зависимости, Изменить, в конец добавить на новую строку curand.lib. Компоновщик, Общие, Дополнительные каталоги библиотек, Изменить, в конец добавить на новую строку $(CUDA_PATH)\lib\x64
4. Создаем файл с расширением .cu, ПКМ по нему, Свойства, Свойства конфигурации, Общие, Тип элемента CUDA C\C++
