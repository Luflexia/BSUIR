Системный подход – рассматривает объект как систему из подсистем, учитывая их структуру, цели и связи между ними.

Методы векторной оптимизации – решают задачи с несколькими критериями, помогая найти наилучший компромисс между ними.

Класс 1. Методы на основе математического программирования
Сначала выбирают главный показатель, а остальные переводят в ограничения или объединяют несколько критериев в одну модель; пример: линейное программирование.

Класс 2. Методы на основе ранжирования показателей
Критерии упорядочиваются по важности, и решение принимается через последовательные уступки; пример: метод Вентцеля.

Класс 3. Методы с обобщённым показателем для сравнения
Создаётся единый показатель, который учитывает все критерии сразу (например, через свёртку или взвешивание); пример: метод Кини, Райфа.

Класс 4. Методы без обобщённого показателя
Альтернативы сравниваются напрямую по всем критериям без объединения в один показатель; пример: метод ELECTRE.

Класс 5. Методы выбора и адаптации решений
Решения формируются с учётом структуры задачи и адаптируются под предпочтения пользователя; пример: метод МКОС.

Метод свёртки – объединяет несколько критериев или подсистем в один обобщённый показатель, чтобы упростить сравнение и оценку решений.

Шкала Харрингтона – переводит любые оценки в диапазон от 0 до 1 и определяет качественный уровень результата (от «очень низкого» до «очень высокого»).
