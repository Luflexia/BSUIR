ЛАБОРАТОРНАЯ РАБОТА №4
4-битный универсальный сдвиговый регистр на JK-триггерах
(аналог 74HC194)
================================================================

НАЗНАЧЕНИЕ КНОПОК (точно по плате)

SW5 (пин P6)  → MR_n          → нажата = полный асинхронный сброс в 0000
SW0 (пин R5)  → PE_n          → нажата = разрешение параллельной загрузки
SW1 (пин U6)  → J             → нажата = J = 1    | отпущена = J = 0
SW2 (пин U5)  → K_n           → нажата = K = 1    | отпущена = K = 0
SW4 (пин T5)  → тактирование  → нажатие = один чистый импульс (антидребезг)
                                отпущена = автоматический режим 1 Гц

НАЗНАЧЕНИЕ СВЕТОДИОДОВ

M26 → Q0 (младший бит)
T24 → Q1
T25 → Q2
R26 → Q3 (старший бит)
F25 → ¬Q3 (инверсный выход старшего бита, внешняя плата)

РЕЖИМЫ РАБОТЫ

1. Параллельная загрузка (SW0 нажата)
   → данные берутся с DIP-переключателей
   → по импульсу CP (SW4 или 1 Гц) загружается сразу всё 4 бита

2. Сдвиг вправо + полная JK-логика на входе (SW0 отпущена)

   SW1   SW2   →   J   K   →   Что делает младший бит при каждом такте
   -----------------------------------------------------------
   отп.  отп.     0   0       УДЕРЖАНИЕ СОСТОЯНИЯ (hold)
   отп.  наж.     0   1       СБРОС В 0 → идёт 0000 вправо
   наж.  отп.     1   0       УСТАНОВКА В 1 → идёт 1111 вправо
   наж.  наж.     1   1       ПЕРЕКЛЮЧЕНИЕ (toggle) → 01010101…

ДОКАЗАТЕЛЬСТВО РАБОТЫ (показывать по порядку)

1. Нажать SW5 → все светодиоды гаснут (сброс)
2. Установить DIP = 1010 → нажать SW0 → нажать SW4 → на светодиодах 1010
3. Отпустить SW0 → теперь режим сдвига
4. Поочерёдно показать 4 режима JK:
   - обе SW1 и SW2 отпущены → значение стоит (удержание)
   - SW2 нажата → идёт 0100 → 0010 → 0001 → 0000
   - SW1 нажата → идёт xxx1 → xx11 → x111 → 1111
   - обе нажаты → младший бит мигает, потом уходит вправо
5. Показать, что внешний светодиод (F25) всегда противоположен старшему биту

ОСОБЕННОСТИ РЕАЛИЗАЦИИ

- Тактирование: 1 Гц автоматически + одиночный импульс от SW4 с антидребезгом
- Полная таблица JK-триггера на входе при сдвиге (как в настоящей 74HC194)
- Асинхронный сброс
- Инверсный выход Q3_n выведен отдельно
