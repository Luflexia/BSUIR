ЛАБОРАТОРНАЯ РАБОТА №4 — ПЕРВАЯ ВЕРСИЯ (исходная)
4-битный универсальный сдвиговый регистр на JK-триггерах
(аналог 74HC194, сделан вручную на структурном уровне)
================================================================

НАЗНАЧЕНИЕ КНОПОК (точно по твоей первой версии)

SW5  (пин P6)  → MR_n        → нажата = полный асинхронный сброс в 0000
SW0  (пин R5)  → PE_n        → нажата = разрешение параллельной загрузки
SW1  (пин U6)  → J           → нажата = J = 0   | отпущена = J = 1
SW2  (пин U5)  → K_n         → нажата = K = 1   | отпущена = K = 0
SW4  (пин T5)  → CP          → каждое нажатие/отпускание = тактовый импульс (без антидребезга!)

НАЗНАЧЕНИЕ СВЕТОДИОДОВ

M26 → Q0 (младший бит)
T24 → Q1
T25 → Q2
R26 → Q3 (старший бит)
F25 → ¬Q3 (инверсный выход старшего бита)

РЕЖИМЫ РАБОТЫ

1. При нажатой SW0 (PE_n = 0)
   → параллельная загрузка с DIP-переключателей
   → по фронту CP (нажатие SW4) загружается значение с DIP

2. При отпущенной SW0 (PE_n = 1)
   → режим сдвига вправо
   → на вход младшего бита (Q0) подаётся полноценная JK-логика:

   SW1     SW2     J   K     Что происходит при каждом такте CP
   -----------------------------------------------------------------
   отп.    отп.    1   0     УСТАНОВКА В 1 → идёт 1111 вправо
   отп.    наж.    1   1     ПЕРЕКЛЮЧЕНИЕ (toggle) → 0101… уходит вправо
   наж.    отп.    0   0     УДЕРЖАНИЕ СОСТОЯНИЯ (ничего не меняется)
   наж.    наж.    0   1     СБРОС В 0 → идёт 0000 вправо

ВАЖНО: в твоей первой версии в коде написано:
J  <= not pushbuttons(2)   → значит при нажатой SW1 → J = 0
K_n <= pushbuttons(3)      → при нажатой SW2 → K = 1

Поэтому таблица именно такая (инверсия на J!)

КАК ПОКАЗЫВАТЬ ПРЕПОДАВАТЕЛЮ (по порядку)

1. Нажать SW5 → всё гаснет (сброс)
2. Установить DIP = 1100 → нажать и держать SW0 → нажать SW4 → отпустить SW0
   → на светодиодах 1100
3. Отпустить SW0 → теперь режим сдвига
4. Показать все 4 подрежима JK:

   • Удержание:        нажать SW1, отпустить SW2 → значение стоит
   • Сброс в 0:        нажать обе SW1 и SW2 → идёт 0000
   • Установка в 1:    отпустить SW1, отпустить SW2 → идёт 1111
   • Переключение:     отпустить SW1, нажать SW2 → младший бит мигает

5. Показать, что светодиод на внешней плате (F25) всегда противоположен старшему биту

ОСОБЕННОСТИ ПЕРВОЙ ВЕРСИИ

- Регистр полностью собран вручную на JK-триггерах (структурная архитектура)
- Полная таблица JK на входе при сдвиге (как в настоящей 74HC194)
- Тактирование напрямую от кнопки SW4 (поэтому может быть небольшой дребезг — нормально для первой версии)
- Инверсный выход Q3_n выведен отдельно
