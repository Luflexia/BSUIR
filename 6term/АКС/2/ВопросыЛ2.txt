Windows
посмотреть список сетевых интерфейсов
netsh interface ipv4 show interfaces

назначить статический ip
netsh interface ip set address "Ethernet 3" static 192.168.1.100 255.255.255.0

Удалить  ip
netsh interface ip delete address "Ethernet 3" addr=ip




Linux
Через ifconfig
поставить ip:
ifconfig enp0s3 27.62.192.222/27

Удалить(административно выкл и вкл):
ifconfig enp0s3 down
ifconfig enp0s3 up

Через  ip
Показать:
ip a или (ip addr show)

Административно выкл и вкл:
ip link set enp0s3 down/up

Присвоить ip:
ip addr add 27.62.192.222/27 dev enp0s3

Удалить ip:
ip addr del 27.62.192.222/27 dev enp0s3
