Программный модуль адаптивного поведения персонажей 2D-игры в жанре ActionRPG

Характеристика:
Дипломный проект представляет собой создание 2D пиксельной игры в жанре ActionRPG с процедурной генерацией уровней, динамической боевой системой и метапрогрессией (системой внутриигровых механик, позволяющая персонажу развиваться вне рамок основного игрового процесса). В игре планируются четыре направления атаки, модификаторы, система выбора улучшений, сбор ресурсов и динамическая музыка. В качестве основных инструментов используются Unreal Engine 5, C++, Paper2D, Tilemap. Реализация пользовательского интерфейса с помощью системы UMG (Unreal Motion Graphics). Сохранение метапрогрессии, настройки и сохранения игрока реализовано через базу данных SQLite. Итоговой целью является функционирующая игра, демонстрирующая реализацию алгоритмов генерации, адаптивное поведение врагов и взаимодействие игровых подсистем.

Вопросы:
Data Tables используется для статических данных (характеристики модификаторов, врагов, оружия, цен). БД используется  для динамических данных. В БД будут храниться: метапрогрессия (глобальные улучшения, открытый контент), настройки (управления, громкости), сохранение текущего забега.
Data Tables читаются один раз и при обращении получаем мгновенный доступ из памяти. Запросы к БД только во время сохранений и выхода из игры.

Касаемо управлением памяти:
Все игровые объекты (персонажи, враги, компоненты, ассеты) наследуются от UObject - базового класса, их жизненным циклом управляет встроенный Garbage Collector (GC).
Для избежания висячих указателей после уничтожения объекта Garbage Collector ом буду использовать умные указатели Unreal Engine (стандартные умные указатели адаптированные под движок). 

TWeakObjectPtr (Unreal версия weak_ptr) хранит слабую ссылку на объект, не мешает GC удалить объект, когда сбрасывается указатель, объект не удаляется, становится пустым. Например, враги держат указатель на игрока, после смерти игрока GC удалит объект из памяти, но обращение к указателю вернет false, вместо мусора из освобожденной памяти, если бы использовали другой указатель.

TUniquePtr (Unreal версия unique_ptr) уникальное владение объектом (кэш уровня, состояние врага), когда сбрасывается указатель, удаляется и объект.

TSharedPtr (Unreal версия shared_ptr) нужен в случае когда владельцев несколько, например "зелье здоровья" есть у игрока и у врага, и когда зелье пропадет у всех владельцев, объект удаляется.
