Тема: "Программный модуль интеллектуального поведения персонажей 2d-игры в жанре rogue-lite"

Вариант 1:
Дипломный проект включает разработку программного модуля для интеллектуального поведения персонажей в 2D-игре жанра rogue-lite. Интеллектуальное поведение врагов реализует паттерны поведения (атаки, уклонения, групповые тактики), навигацию по процедурно генерируемым комнатам с препятствиями. Механики: процедурная генерация уровней, зачистка комнат для улучшений оружия, сбор ресурсов для метапрогрессии в хабе. Технологии: Unreal Engine 5 с Paper2D для 2D-элементов, Tilemap для уровней. Ассеты — бесплатные, с доработкой. Результат: модуль интеллектуального поведения, сохранением прогресса, UI (меню, HUD), динамической музыкой (3+ композиций) и оптимизацией.


Вариант 2:
Дипломный проект представляет собой разработку программной части 2D rogue-lite игры (top-down вид) с процедурно генерируемыми комнатами, системой атак в 4 направлениях, модификаторами оружия и метапрогрессией (разблокировка уникальных улучшений вне игровых забегов). Механики: зачистка комнат для апгрейдов в рамках забега, ИИ врагов с паттернами, динамическая музыка (собственные 3+ композиций). Технологии: Unreal Engine 5, Paper2D для спрайтов/анимаций, Tilemap для уровней. Готовые ассеты из бесплатных источников. Итог: полноценная игра с сохранением прогресса, UI (меню, HUD) и оптимизацией, демонстрирующая алгоритмы генерации и интеграцию подсистем.
