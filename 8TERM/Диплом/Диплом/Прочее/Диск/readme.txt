1. ОПИСАНИЕ ПРОЕКТА
--------------------------------------------------------------------------------

Depthrun, это дипломный проект, выполненный в виде 2D top-down рогалика
с процедурно генерируемыми подземельями. Игра написана на движке
Unreal Engine 5.7 с использованием плагина Paper2D и языка C++.

Главный результат работы – это собственный программный модуль
адаптивного поведения врагов (AdaptiveBehavior). Модуль реализован полностью
на C++ без использования штатных систем искусственного интеллекта Unreal
Engine (без Behavior Tree, Blackboard, EQS и без машинного обучения). Модуль
устроен как трехслойный конвейер принятия решений поверх классического FSM
(конечного автомата) с пятью состояниями: Idle, Chase, Attack, Retreat, Flank.

Сама игра выступает демонстрационным полигоном для модуля. Игрок проходит
процедурно сгенерированный данж, сражается с врагами, собирает алмазы и
улучшения, прокачивается в хабе между забегами и в финале сражается с боссом.

Платформа: Windows 10 / 11, 64 бита.

--------------------------------------------------------------------------------
2. СОДЕРЖИМОЕ ДИСКА
--------------------------------------------------------------------------------

На диске находятся три файла:

  1) Depthrun.zip      архив с проектом (исходники + собранная игра)
  2) depthrun.pptx     презентация к защите дипломной работы
  3) readme.txt        файл с инструкцией

Чтобы начать работу с проектом, нужно распаковать архив Depthrun.zip в любую
удобную папку на диске. Распаковать можно стандартными средствами Windows: правой
кнопкой мыши по архиву, пункт "Извлечь все...". Также подойдут программы
WinRAR или 7-Zip.

ВАЖНО: путь до распакованной папки желательно делать коротким и без русских
букв и пробелов. Это важно прежде всего для сборки из исходников через
Unreal Engine.

--------------------------------------------------------------------------------
3. СОДЕРЖИМОЕ АРХИВА Depthrun.zip
--------------------------------------------------------------------------------

После распаковки архива внутри будут две папки:

  Source/    исходный код проекта в формате Unreal Engine 5.7.
             Здесь лежат: файл проекта Depthrun.uproject, папки Source,
             Content, Config, Plugins, Build и другие служебные папки.
             Эту папку используют, если хочется самостоятельно открыть
             проект в редакторе Unreal Engine, изучить код или собрать
             игру с нуля.

  Game/      готовая собранная версия игры под Windows 64-бит.
             Здесь уже лежит исполняемый файл Depthrun.exe и все
             необходимые ресурсы. Запускается без установки Unreal Engine
             и без компилятора, просто двойным кликом по exe-файлу.

Если нужно просто посмотреть и поиграть, достаточно папки Game.
Если нужно открыть проект в редакторе или пересобрать, используйте Source.

--------------------------------------------------------------------------------
4. ВАРИАНТ 1. ЗАПУСК ГОТОВОЙ СОБРАННОЙ ИГРЫ
--------------------------------------------------------------------------------

Это самый простой способ. Никаких дополнительных программ устанавливать
не нужно (кроме, возможно, Visual C++ Redistributable, см. пункт 7).

Шаги:

  1) Распаковать архив Depthrun.zip в любую удобную папку.
  2) Открыть папку Game внутри распакованного архива.
  3) Найти файл Depthrun.exe.
  4) Запустить его двойным кликом мыши.
  5) Игра запустится в полноэкранном режиме. Главное меню, кнопка Play.

Закрыть игру можно через меню или клавишей Alt + F4.

--------------------------------------------------------------------------------
5. ВАРИАНТ 2. СБОРКА И ЗАПУСК ИЗ ИСХОДНИКОВ
--------------------------------------------------------------------------------

Этот способ нужен, если вы хотите открыть проект в редакторе Unreal Engine,
посмотреть код, изменить что-то или собрать игру самостоятельно.

ШАГ 5.1. УСТАНОВКА EPIC GAMES LAUNCHER И UNREAL ENGINE 5.7

  1) Скачать Epic Games Launcher с официального сайта:
     https://store.epicgames.com/ru/download
  2) Установить лаунчер, запустить его. При первом запуске потребуется
     создать бесплатную учетную запись Epic Games или войти в уже
     существующую.
  3) В лаунчере перейти на вкладку "Unreal Engine" (слева).
  4) В верхней части окна выбрать раздел "Библиотека".
  5) Нажать "+" рядом с надписью "Версии движка" и выбрать версию 5.7.
  6) Нажать "Установить". Установка движка занимает 60-100 ГБ
     дискового пространства и может длиться от 30 минут до нескольких
     часов в зависимости от скорости интернета.

ШАГ 5.2. УСТАНОВКА VISUAL STUDIO 2026

  Без Visual Studio проект на C++ не соберется, движок просто не сможет
  скомпилировать исходники.

  1) Скачать Visual Studio 2026 Community (бесплатная версия):
     https://visualstudio.microsoft.com/ru/downloads/
  2) Запустить установщик. В окне выбора компонентов поставить галочку
     на "Разработка игр на C++" (Game development with C++).
  3) Справа в списке компонентов убедиться, что отмечены:
     - MSVC v143 (последняя версия)
     - Windows 10 SDK или Windows 11 SDK
     - Unreal Engine Installer
  4) Нажать "Установить". Установка занимает около 15-30 ГБ.
  5) После установки перезагрузить компьютер.

ШАГ 5.3. ОТКРЫТИЕ ПРОЕКТА В РЕДАКТОРЕ

  1) Перейти в распакованную папку Source.
  2) Найти файл Depthrun.uproject.
  3) Кликнуть по нему правой кнопкой мыши и выбрать пункт
     "Generate Visual Studio project files" ("Создать файлы проекта
     Visual Studio"). Подождать 1-3 минуты.
  4) Дважды кликнуть по Depthrun.uproject. Откроется Unreal Engine,
     возможно, появится окно "Missing Modules" с предложением
     перекомпилировать проект, нажать "Yes". Компиляция займет
     5-15 минут на первом запуске.
  5) После компиляции откроется редактор Unreal Engine с проектом
     Depthrun. Чтобы запустить игру прямо в редакторе, нажмите
     кнопку Play в верхней панели (зеленый треугольник).

ШАГ 5.4. СБОРКА АВТОНОМНОГО EXE-ФАЙЛА (ПАКЕТИРОВАНИЕ)

  Если нужно собрать собственный exe, как в папке Game:

  1) Открыть проект в редакторе Unreal Engine (см. шаг 5.3).
  2) В верхнем меню выбрать: Platforms -> Windows -> Package Project.
  3) Указать папку, в которую будет сохранена собранная игра.
  4) Дождаться окончания сборки (от 10 минут до часа). В указанной
     папке появится готовый Depthrun.exe со всеми ресурсами.

ШАГ 5.5. СБОРКА ЧЕРЕЗ VISUAL STUDIO (ДЛЯ РАЗРАБОТКИ)

  1) Открыть Depthrun.sln двойным кликом (он появится после
     генерации файлов проекта VS, см. шаг 5.3, пункт 3).
  2) В верхней панели Visual Studio выбрать конфигурацию
     "Development Editor" и платформу "Win64".
  3) Нажать Build -> Build Solution или клавишу F7.
  4) После успешной сборки можно запускать редактор через
     Depthrun.uproject или прямо из Visual Studio (F5).

  ВАЖНО: для работы редактора всегда используйте конфигурацию
  Development Editor, а не DebugGame Editor.

--------------------------------------------------------------------------------
6. ВОЗМОЖНЫЕ ПРОБЛЕМЫ И ИХ РЕШЕНИЕ
--------------------------------------------------------------------------------

ПЕРВОЕ, ЧТО СТОИТ ПОПРОБОВАТЬ ПРИ ЛЮБЫХ ПРОБЛЕМАХ - ОТКЛЮЧИТЬ VPN.

Многие странности Unreal Engine и проекта связаны именно с активным
VPN-подключением. В частности:
  - не открывается Depthrun.uproject, движок зависает или выдает ошибку;
  - нет звука в редакторе Unreal Engine;
  - не подгружаются ресурсы, долго стартует редактор;
  - случайные сбои при компиляции.

Если столкнулись с чем-то подобным - отключите VPN полностью, закройте
редактор и попробуйте снова. В большинстве случаев это решает проблему.

Проблема: при запуске Depthrun.exe выдается ошибка про отсутствие
          MSVCP140.dll, VCRUNTIME140.dll или похожую.
Решение:  установите Microsoft Visual C++ Redistributable for Visual
          Studio 2015-2022 (x64). Скачать можно с официального сайта
          Microsoft:
          https://aka.ms/vs/17/release/vc_redist.x64.exe
          После установки перезагрузить компьютер и снова запустить игру.

Проблема: Windows SmartScreen блокирует запуск exe.
Решение:  нажать "Подробнее" -> "Выполнить в любом случае". Так
          происходит, потому что у проекта нет платной цифровой подписи.

Проблема: при открытии Depthrun.uproject движок требует пересобрать
          модули, нажимаю Yes, появляется ошибка компиляции.
Решение:  убедитесь, что установлены Visual Studio 2022 и нагрузка
          "Разработка игр на C++" (см. шаг 6.2). Затем правой кнопкой
          по Depthrun.uproject -> "Generate Visual Studio project files",
          открыть Depthrun.sln и собрать его в Visual Studio в режиме
          Development Editor (см. шаг 6.5).

Проблема: игра запускается, но FPS очень низкий.
Решение:  проверьте, что используется дискретная видеокарта, а не
          встроенная. В настройках Windows: "Параметры графики" ->
          "Обзор" -> добавить Depthrun.exe -> "Высокая
          производительность".

Проблема: пропадает звук или странно ведет себя ввод.
Решение:  попробуйте перезапустить игру. Если не помогло, удалите папку
          Saved (она будет пересоздана автоматически) рядом с .exe,
          либо в папке проекта Source.

7. ГДЕ ХРАНЯТСЯ СОХРАНЕНИЯ И БАЗА ДАННЫХ
--------------------------------------------------------------------------------

Игра хранит весь прогресс игрока (накопленные алмазы, купленные апгрейды
в хабе, история забегов) в одном файле базы данных SQLite. Путь к этому
файлу зависит от того, каким способом запущена игра.

ЗАПАКОВАННАЯ ИГРА (Depthrun.exe из папки Game или собственный билд):

  %LOCALAPPDATA%\Depthrun\Saved\Depthrun.db

  Полностью это выглядит примерно так:

  C:\Users\<имя пользователя Windows>\AppData\Local\Depthrun\Saved\Depthrun.db

  Чтобы быстро открыть эту папку, нажмите Win + R и вставьте:

  %LOCALAPPDATA%\Depthrun\Saved\

  Важный момент: эта папка НЕ удаляется при пересборке игры и НЕ
  перезаписывается при установке новой версии. Прогресс сохраняется
  между разными сборками. Если нужно начать с нуля, удалите файл
  Depthrun.db (или всю папку Saved по этому пути), при следующем
  запуске игра создаст пустую базу автоматически.

ЗАПУСК ИЗ РЕДАКТОРА UNREAL ENGINE (PIE, Play In Editor):

  <папка проекта>\Saved\Depthrun.db

  То есть рядом с Depthrun.uproject в подпапке Saved. Это совсем другой
  файл, не связанный с сохранениями запакованной игры.

ПРОСМОТР СОДЕРЖИМОГО БАЗЫ:

  Файл Depthrun.db, это обычная база SQLite. Открыть и посмотреть её
  можно бесплатными программами, например DB Browser for SQLite
  (https://sqlitebrowser.org/) или расширением для VSCode
  "SQLite Viewer".

  В базе две таблицы:
    - player_profile  накопленные алмазы и уровни апгрейдов (одна строка)
    - run_history     история всех забегов: исход, длительность,
                      количество зачищенных комнат, время.
