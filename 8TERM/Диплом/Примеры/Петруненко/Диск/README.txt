@SignLanguageBot is a Telegram bot created to align the rights 
between social layers. It's called to help deaf and muted people and also their relatieves
and friends to easier brake the communication barrier. 

To deploy the application, unarchive the SignLanguageModel.rar, install python 3.12 or newer
Then, execute the command "pip3 install requirements.txt" 
and make sure, that all PATH variables are created(might need a reload) 

Now, get to the Telegram and search for the @SignLanguageBot. Enjoy!
