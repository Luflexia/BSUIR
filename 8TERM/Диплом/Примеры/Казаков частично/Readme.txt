Многопользовательская 3D игра с интеграцией в Telegram

Mice — это многопользовательская 3D-игра, интегрированная с мессенджером Telegram. Игроки соревнуются в сборе предметов на процедурно-генерируемых уровнях, используют бонусы с сетевыми эффектами и избегают ловушек. Проект включает клиентскую часть (игра на Unity), серверную часть (FastAPI) и Telegram-бота для аутентификации и запуска.

Для разработки использовались: среда разработки Unity и Visual Studio, язык программирования C# для клиентской части, язык программирования Python для серверной части и Telegram-бота.

Функционал
- Запуск игры через Telegram WebApp с автоматической авторизацией по username.
- Создание и подключение к игровым лобби (до 4 игроков) с поддержкой чата.
- Процедурная генерация уникальных 3D-локаций на основе единого seed.
- Синхронизация позиций, поворотов и действий игроков в реальном времени через WebSocket.
- Сбор обычных и бонусных предметов с динамическим обновлением таблицы очков.
- Система ловушек с потерей очков и временным отключением управления.
- Локальные и сетевые бонусные эффекты (ускорение, замедление, отключение/инверсия управления).
- Серверный таймер с синхронизацией времени для всех участников.
- Финальная панель с результатами и возврат в главное меню.

Запуск и развертывание проекта

Предварительные требования

Перед началом работы убедитесь, что на вашей системе установлены:
1. Unity Hub и Unity Editor (версия 2022.3.62f2 или выше);
2. Git для работы с репозиториями;
3. Python (версия 3.12.5 или выше);
4. pip (менеджер пакетов Python);
5. аккаунт на GitHub для хостинга сборки;
6. аккаунт на Render для развертывания сервера и бота.

Установка необходимого программного обеспечения

Unity Hub и Unity Editor

Перейдите на официальный сайт Unity: https://unity.com/ru/download

Скачайте и установите Unity Hub для вашей операционной системы.

После установки Unity Hub, перейдите в раздел «Installs» и нажмите «Install Editor».

Выберите версию 2022.3.62f2 (или более новую LTS-версию). При выборе компонентов обязательно отметьте:
- WebGL Build Support (необходим для сборки игры под WebGL)

Дождитесь завершения установки.

Проверьте установку, запустив Unity Hub и убедившись, что выбранная версия отображается в списке установленных.

Git

Перейдите на официальный сайт Git: https://git-scm.com/downloads

Скачайте и установите версию для вашей операционной системы (Windows, macOS или Linux).

При установке можно оставить все настройки по умолчанию.

Проверьте установку, выполнив в терминале или в командной строке:

git --version

На экране должна появиться установленная версия Git, например: git version 2.40.0.windows.1

Python

Перейдите на официальный сайт Python: https://www.python.org/downloads/

Скачайте и установите версию 3.12.5 или выше для вашей операционной системы.

При установке обязательно отметьте опцию «Add Python to PATH» (Добавить Python в переменные среды).

Проверьте установку, выполнив в терминале:

python --version

На экране должна появиться установленная версия Python, например: Python 3.12.5

pip

pip устанавливается вместе с Python автоматически (начиная с версии Python 3.4). Для проверки выполните в терминале:

pip --version

Если pip не установлен, его можно установить командой:

python -m ensurepip --upgrade

Настройка Telegram-бота

1. Создайте нового бота через @BotFather в Telegram:
- Отправьте команду /newbot.
- Придумайте имя и username для бота (username должен заканчиваться на bot).
- Сохраните полученный токен для доступа к API.

2. Создайте репозиторий на GitHub и загрузите в него все файлы бота.

3. Разверните бота на платформе Render:
- Войдите в аккаунт Render и нажмите New + → Web Service.
- Подключите репозиторий с ботом.
- Укажите следующие настройки:
Build Command: make install
Start Command: make start
- Добавьте переменные окружения:
PYTHON_VERSION: 3.12.5
TELEGRAM_TOKEN: токен, полученный от @BotFather
- Нажмите Create Web Service. Render автоматически соберет и запустит бота.

Настройка серверной части (FastAPI)

1. Создайте репозиторий на GitHub и загрузите в него файлы сервера.

2. Разверните сервер на платформе Render:
- Нажмите New + → Web Service.
- Подключите репозиторий с сервером.
- Укажите следующие настройки:
Build Command: pip install -r requirements.txt
Start Command: uvicorn miceserver:app --host 0.0.0.0 --port $PORT
- Добавьте переменную окружения:
PORT: 10000
- Нажмите Create Web Service. После успешного развертывания сервер будет доступен по URL вида https://[service-name].onrender.com.

Настройка и сборка клиентской части (игра на Unity)

1. Откройте проект Unity (папка с исходными файлами игры) в Unity Hub.

2. Убедитесь, что в скрипте WebSocketConnect указан актуальный адрес сервера:
- Найдите строку: websocket = new WebSocket("wss://miceserver.onrender.com/ws/lobby");
- При необходимости замените URL на адрес вашего развернутого сервера.

3. Выполните сборку проекта в WebGL:
- Перейдите в меню File → Build Settings.
- Выберите платформу WebGL и нажмите Switch Platform.
- Нажмите Build и выберите папку для сборки.

4. После сборки загрузите содержимое папки сборки в репозиторий GitHub.

5. В настройках репозитория включите GitHub Pages:
- Перейдите в Settings → Pages.
- В разделе Branch выберите ветку с собранными файлами (обычно main или master).
- Сохраните настройки. Игра станет доступна по ссылке вида https://[username].github.io/[repository-name]/.

Финальная настройка игры

1. После развертывания сервера скопируйте его URL.

2. В проекте Unity в скрипте WebSocketConnect обновите URL WebSocket-соединения:
- Замените wss://старый-адрес/ws/lobby на wss://новый-адрес/ws/lobby.

3. Пересоберите WebGL-сборку и загрузите обновленные файлы в репозиторий GitHub Pages.

4. Убедитесь, что в коде бота указан актуальный GAME_URL (ссылка на GitHub Pages с игрой).

Запуск игры

1. Откройте Telegram и найдите созданного бота.

2. Отправьте команду /start.

3. Нажмите кнопку «Start Game». Откроется WebApp с игрой.

4. В главном меню нажмите «Play», затем «Create a lobby» или «Join the lobby».

5. Дождитесь подключения других игроков и нажмите «Start game» (только для создателя лобби).
